# ninho — landing page

LP estática do pacote digital do chalé ninho (42 m², R$ 447). HTML/CSS puro, sem build.

- Publicado via GitHub Pages: https://vinicius559.github.io/ninho-chale/
- **Checkout:** placeholder. Colar o link Kiwify/Hotmart em `CHECKOUT_URL` no fim do `index.html`.
- **Meta Pixel:** placeholder comentado no `<head>` (sem ID). Botões já têm `data-track`.
- Imagens: `build_images.py` (rodar de `earny/chale/`) regenera `img/*.webp`, `og-image.jpg` e favicons.
- Screenshots: `shoot.py` (Playwright).
